# E-commerce Sales Analytics 

## Project Overview
This folder hosts an end-to-end data analytics and business intelligence suite built to evaluate e-commerce operations, consumer behavior, and financial performance etc. Moving away from localized flat files, this architecture integrates raw data pipelines from Kaggle dataset, into an analytical SQL database, which subsequently powers a series of specialized, interactive Power BI executive dashboards.

## Data Source
Due to file size constraints on GitHub, the full raw dataset is hosted externally. You can download the original source data used for this project here:
* **[Kaggle Dataset Source Link](https://www.kaggle.com/datasets/datascikhan/e-commerce-sales-and-customer-analytics)**

## Tech Stack & Architecture
* **Initial Data understanding & Manipulation:** MS Excel
* **Data Ingestion & Storage:** SQL Server / PostgreSQL (Relational modeling, schemas)
* **Transformation & Business Logic:** Advanced SQL (CTEs, Window Functions, Views, Indexing)
* **Visualization & BI:** Power BI Desktop (DAX measures, star schema modeling, interactive pages)
* **Version Control:** Git & GitHub

---

## Folder Architecture
This folder functions as an umbrella platform housing multiple independent analytics projects derived from the exact same e-commerce dataset. Each project contains its own targeted SQL scripts, Power BI file, and visual exports.

* **Project 1 :** Global Regional Sales & Customer Analytics Dashboard
