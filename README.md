# Business-Analyst-Models-Diagrams

A repository of hands-on Business Analysis frameworks applied to financial systems, risk workflows, and data analytics case studies.

## What's Inside

* **BPMN**: Standardized BPMN process models and workflow diagrams mapping business operations.
* **E-Commerce Sales Analytics**: Interactive dashboard exports and data analytics insights for customer and sales performance.
* **loan_origination_project_neocred**: End-to-end business analysis case study analyzing loan application workflows, drop-off points, and process optimization.
